# Готовые бесплатные звуки

В игре используются 18 готовых Ogg Vorbis записей с лицензией **CC0 1.0**
и пользовательский MP3 для начала боя. Файлы скопированы без изменения содержимого.
Синтеза эффектов и генерации речи в проекте нет.

| Набор | Автор | Использование |
| --- | --- | --- |
| [RPG Audio](https://kenney.nl/assets/rpg-audio) | Kenney Vleugels | Двери, снасти, бумага, карты, монеты, металлические механизмы |
| [Impact Sounds](https://kenney.nl/assets/impact-sounds) | Kenney Vleugels | Мастерская, дерево, колокол доски лидеров, удары и защита |
| [Voiceover Pack (Fighter)](https://kenney.nl/assets/voiceover-pack-fighter) | Kenney Vleugels | Готовые мужские реплики You win / You lose |
| [40 CC0 water / splash / slime SFX](https://opengameart.org/content/40-cc0-water-splash-slime-sfx) | rubberduck | Лодка, заброс и поклёвка |

Лицензия библиотечных звуков: https://creativecommons.org/publicdomain/zero/1.0/
Оригинальные лицензии Kenney сохранены рядом в `LICENSE-*.txt`.
Для water-пака CC0 указан на авторской странице OpenGameArt; архив не содержит отдельного файла лицензии.
`sources.json` сопоставляет каждый игровой файл с исходным названием, автором,
страницей набора, лицензией и SHA-256. Дата загрузки: 16 ноября 2026.

`src/sound.ts` только загружает и воспроизводит записи: регулирует громкость,
делает наведение коротким и тихим, ограничивает частые повторы и отключает звук.
При начале боя `fight.mp3` проигрывается один раз на обычной скорости вместе с заставкой.
Это точная копия добавленного пользователем `sound/nta3mde5ntg0nta3mtew_n4ltgrxccn4.mp3`.
Автор и лицензия этого файла не указаны; к звукам CC0 он не относится.
Продолжительность записи около 1.93 секунды, заставки — 2.1 секунды.
Все файлы включаются в сборку; внешние сервисы во время игры не нужны.
